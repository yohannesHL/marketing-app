# Workspace redesign implementation

1. Shared shell and design tokens: public landing, authenticated navigation, mobile navigation, existing social/connections/sign-in integration.
2. Durable workspace: owned campaign drafts, brand rules, scoped summary/API, dashboard, campaign library/details, content studio.
3. Campaign flow: URL/brief/type, earlier channels, type-specific plan and creative inputs, approved social execution and truthful paid/draft delivery states.
4. Integration and validation: schema migration, typecheck, behavior/security tests, Mockoon browser walkthroughs at desktop/mobile sizes; preserve existing publishing controls.

Each phase is tested before final integration. Research and approval are captured in the design document. Existing Next 15, React 18, Tailwind 3 and DaisyUI remain; no framework migration.
